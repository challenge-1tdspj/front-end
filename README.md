# Portal HC - Tutorial

Este projeto é uma página web de tutorial para o Portal do Paciente HC, com informações, perguntas frequentes (FAQ), contato, integrantes e redes sociais.

## Estrutura do Projeto

- `index.html`: Página principal com tutorial passo a passo.
- `css/style.css`: Estilos personalizados responsivos.
- `js/`: Scripts JavaScript para interatividade (menu lateral, FAQ, formulários, etc).
- `img/`: Imagens utilizadas no tutorial e nos cartões de integrantes/redes sociais.
- `paginas/`: Páginas adicionais (FAQ, Contato, Integrantes, Redes Sociais).

## Funcionalidades

- Tutorial visual e interativo sobre o uso do Portal do Paciente HC.
- Menu lateral responsivo para navegação.
- Página de FAQ com perguntas frequentes.
- Página de contato com formulário validado e salvamento local.
- Página de integrantes com informações e links para redes sociais.
- Página de redes sociais oficiais do Hospital das Clínicas.

## Como Executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Navegue pelas páginas usando o menu.

## Tecnologias Utilizadas

- HTML5
